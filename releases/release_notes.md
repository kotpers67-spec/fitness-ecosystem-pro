# Fitness Ecosystem Pro — Релиз v1.0.0

## 📱 Включенные приложения:

### 1. Trainer Pro (`trainer-pro-v1.0.0.apk`)
- **Быстрый поиск клиентов**: фильтрация базы подопечных по ФИО и номеру телефона.
- **Привязка подопечных**: добавление клиентов по 6-значному PIN-коду и сканированию QR.
- **Управление доступом**: переключатель разрешения на самостоятельное выполнение тренировок для подопечного.
- **Журнал тренировок**: селектор дат, калькулятор блинов на штангу (20/15/10/5/2.5/1.25 кг), калькулятор 1ПМ, таймер отдыха с гонгом и вибрацией.
- **5 тем и 5 стилей интерфейса**: Cyber Lime, Electric Blue, Crimson Power, Clean Swiss, Nordic Emerald.

### 2. Athlete Pro (`athlete-pro-v1.0.0.apk`)
- **Изоляция данных**: каждый подопечный изолирован по уникальному UUID, доступ к чужим данным исключен.
- **Настройка профиля**: выбор и автоматическое сжатие аватара из галереи (512x512 JPEG), телефон, цели и ограничения.
- **Связывание с тренером**: генерация 6-значного PIN-кода и QR-кода, возможность отвязаться от наставника.
- **Режим Только чтение**: защита от случайного изменения подходов, пока тренер не выдал разрешение.
- **Фоновая авто-синхронизация**: обновление данных через Google Drive при открытии приложения и завершении тренировки.

---

## 🔒 Безопасность:
- **Zero Plaintext Secrets**: сквозное маскирование секретных ключей в `CloudSecurityManager.kt`.
- **Zero-Login Cloud Sync**: работа через защищенный Google Apps Script Web App Endpoint без необходимости авторизации аккаунтов.
