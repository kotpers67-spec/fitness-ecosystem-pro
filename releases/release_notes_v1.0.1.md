# Fitness Ecosystem Pro — Версия 1.0.1

## 📱 Включенные приложения:
1. **Trainer Pro (`trainer-pro-v1.0.1.apk`)**
   - Полное управление каталогом упражнений (добавление, редактирование, удаление, фильтрация по группам мышц, поиск).
   - Чистый запуск: база клиентов создается пустой и заполняется тренером.
   - Управление темами (5 палитр: Cyber Lime, Electric Blue, Crimson Power, Clean Swiss, Nordic Emerald).
   - Привязка подопечных по 6-значному PIN-коду и QR-коду через Google Диск.
   - Полноэкранный темный интерфейс (Edge-to-Edge, устранение белых полос).

2. **Athlete Pro (`athlete-pro-v1.0.1.apk`)**
   - Профиль атлета с возможностью редактирования ФИО, телефона, целей, ограничений и фото-аватара.
   - Чистый запуск без предустановленных данных и без автоматической ложной привязки.
   - Генерация 6-значного PIN-кода и QR-кода для связывания со своим тренером.
   - Кнопка отвязки от тренера с мгновенной генерацией нового PIN/UUID.
   - Режим Read-Only с разблокировкой при допуске тренера.
   - Полная изоляция личных данных в Google Диске по уникальному UUID.

## 🚀 Установка:
Скачайте APK-файлы из секции **Assets** ниже и установите на Android-устройство (Android 8.0+).
