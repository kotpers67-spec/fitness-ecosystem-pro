# Fitness Ecosystem Pro (Trainer Pro & Athlete Pro)

Экосистема для персональных фитнес-тренеров и их подопечных с нулевой зависимостью от сторонних платных серверов, сквозным шифрованием и облачной синхронизацией через Google Drive.

---

## 📱 Архитектура и компоненты

### 1. Trainer Pro (`trainer-app`)
Приложение для фитнес-тренера (Android, Kotlin, Jetpack Compose, Material 3, Room SQLite):
- **Селектор клиентов с быстрым поиском**: фильтрация базы по ФИО и номеру телефона.
- **Привязка подопечных по 6-значному PIN-коду и QR-коду**: мгновенное спаривание в зале.
- **Журнал тренировок**: селектор дат, калькулятор блинов на штангу (20/15/10/5/2.5/1.25 кг), калькулятор 1ПМ, таймер отдыха со звуковым гонгом и виброоткликом.
- **Управление доступом**: переключатель *«Разрешить самостоятельное выполнение на [дата]»* для дней, когда подопечный тренируется без личного присутствия тренера.
- **Аналитика и прогресс**: графики веса тела, динамика 1RM и тоннажа по упражнениям.
- **5 цветовых тем и 5 компоновок**: Cyber Lime, Electric Blue, Crimson Power, Clean Swiss, Nordic Emerald.

### 2. Athlete Pro (`athlete-app`)
Приложение для подопечного атлета (Android, Kotlin, Jetpack Compose, Material 3, Room SQLite):
- **Изоляция данных и конфиденциальность**: доступ строго к своим весам, замерам и тренировкам по постоянному UUID.
- **Профиль атлета**: выбор и сжатие аватара из галереи, номер телефона, цели, ограничения.
- **Связывание с тренером**: генерация персонального 6-значного PIN и QR-кода, возможность отвязаться и перепривязаться к новому наставнику.
- **Режим Read-Only / Защита от случайных изменений**: подопечный видит план, историю и графики, но не может менять веса, если тренер не открыл доступ на самостоятельное выполнение.
- **Фоновая авто-синхронизация**: обновление при запуске и при завершении тренировки.

---

## 🔒 Безопасность и Синхронизация

- **Google Drive Sync (Zero-Login)**: Синхронизация через защищенный Google Apps Script Web App Endpoint.
- **Шифрование ключей**: Сквозное маскирование секретов в `CloudSecurityManager.kt` (Zero Plaintext Secrets).
- **Изоляция по UUID**: Данные каждого подопечного хранятся в изолированном дереве `clients/{uuid}`.
